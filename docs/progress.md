## 2026-07-26 · 对抗式审查修复轮（v0.2.1）

25 个审查/验证 agent 对 v0.2.0 做了四镜头审查（未来函数/数值/健壮性/测试质量），
9 项确认问题全部修复（每项均带实测复现与回归测试，测试 135 → 146）：

- **[前视偏差] 财报披露滞后**：统一 45 天改为按报告期区分（季报 31 / 半年报 62 /
  年报 120 天，即披露截止日口径）——原先年报最多提前 2.5 个月「可见」
- **[口径错误] 实盘 TWR**：入金改期初流量进分母、出金期末加回分子——原口径在
  「入金当日建仓」时收益按前日小基数放大可达百倍、甚至净值转负
- **[数据完整性] 前复权缓存**：触网改为整段重拉替换缓存——原增量合并会把新旧
  复权基准拼进同一序列，除权后接缝处出现虚假跳空 K 线
- **[对齐] IC 加权合成**：滚动 IC 先对齐行情索引再 shift——原实现最后一个交易日
  （实盘出信号那天）合成因子恒为全 NaN；另按可得因子重归一部分覆盖的股票
- **[方向] 网格扫描排序**：metric=max_drawdown 改升序（回撤最差的曾排第一）
- **[逻辑] 止损跌停顺延**：顺延日冻结该票加仓——否则调仓信号继续摊低均价，
  止损线永远追不上；停牌持仓估值改用最近有效价（原先按 0 塌陷）
- **[缓存] 新鲜但不完整**：新鲜缓存必须覆盖请求起点，否则触网补齐——原先长区间
  请求被短缓存无声截断
- **[提示] 漏记入金**：负现金/零入金时账本报告与净值接口输出明确警告
- **[防御] 前端转义**：missing_price 渲染补 esc()，esc 增加单引号转义
