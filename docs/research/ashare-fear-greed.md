# A 股恐贪指数：FundDB 与 AKShare 公开契约证据笔记

> 研究日期：2026-08-14
> 研究范围：只记录公开页面、公开文档与公开源码目录能够支持的事实；不实现接口，不推测未公开的计算细节。

## 结论摘要

- FundDB 的公开页面是「工具 / 估值情绪 / 恐贪指数」，页面可见当前指数属性、当前指数数值、历史曲线和标的选择器；页面本身没有在可见说明中给出完整公式或数值权重。[FundDB 恐贪指数页面](https://www.funddb.cn/tool/fear)
- `index_fear_greed_funddb` 的历史公开 AKShare 契约只有一个标的参数：`symbol`；公开说明中的可选值为 `上证指数` 和 `沪深300`，默认示例为 `上证指数`，单次返回该标的的全部历史数据。[AKShare 接口公开说明（含目标地址、输入/输出表）](https://jishu.proginn.com/doc/674566248d0c0c4d3)
- 公开响应字段为 `date`、`fear`、`index`：日期、恐贪指数、所选指数点位；公开示例将前两者分别展示为日期和 `float64` 恐贪值，`index` 为对应指数数值。[AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)
- 韭圈儿公开科普把该指数描述为六项情绪指标综合加权，读数范围为 0–100；但公开材料没有给出六项的数值权重、标准化窗口、各项具体变换公式或缺失值处理规则。[韭圈儿公开科普：恐惧贪婪指数](https://www.weibo.com/ttarticle/p/show?id=2309404636475210989882)

## 1. FundDB 页面公开内容

### 1.1 页面与展示字段

本次对 [FundDB 恐贪指数页面](https://www.funddb.cn/tool/fear) 做页面核验，页面公开可见的结构包括：

| 页面区域 | 可确认的公开内容 |
| --- | --- |
| 页面归属 | 工具 → 估值情绪 → 恐贪指数 |
| 当前值卡片 | 「当前指数属性」「当前指数数值」两个展示字段，并配有「极度恐惧」「极度贪婪」区间提示 |
| 历史区 | 「往期指数」、恐惧贪婪历史图表、时间窗口切换 |
| 标的控件 | 指数选择器；页面初始选择显示为「上证指数」 |
| 风险提示 | 页面提示相关数据仅供参考，不构成投资指导与建议 |

以上是页面层面的公开展示字段，不等同于 FundDB 对外承诺的稳定 JSON schema；页面未公开展示完整 API 响应结构。[FundDB 恐贪指数页面](https://www.funddb.cn/tool/fear)

### 1.2 可选标的与口径

AKShare 的公开接口说明将该页面作为目标地址，并把 `symbol` 的公开选项写为：

| `symbol` | 口径 |
| --- | --- |
| `上证指数` | 以 FundDB 页面上的上证指数序列作为对照指数 |
| `沪深300` | 以 FundDB 页面上的沪深300指数序列作为对照指数 |

说明表中的默认示例是 `symbol="上证指数"`，并注明单次调用返回所有数据；因此这不是“任意 A 股个股代码”的接口，而是两个市场基准口径的历史情绪序列接口。[AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)

## 2. AKShare `index_fear_greed_funddb` 公开 API 契约

### 2.1 输入

公开说明只列出一个输入参数：

```text
symbol: str
默认示例: "上证指数"
可选值: {"上证指数", "沪深300"}
```

该说明同时把目标地址指向 `https://funddb.cn/tool/fear`，接口描述为 FundDB 的“工具-估值情绪-恐惧贪婪指数”。[AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)

### 2.2 响应字段

公开输出表为三列：

| 字段 | 公开类型/含义 | 证据边界 |
| --- | --- | --- |
| `date` | `object`；示例值为 `YYYY-MM-DD` 日期 | 文档没有声明时区、交易日历补齐或缺失日期处理规则 |
| `fear` | `float64`；恐惧贪婪指数 | 文档将其标为恐惧贪婪指数，没有进一步给出计算公式 |
| `index` | `float64`；与 `symbol` 对应的指数点位 | 不是另一个情绪子指标，而是用于和 `fear` 对照的指数序列 |

公开示例返回形状为三列历史表，示例数据从 2022-04-19 开始；示例行数和最新日期属于文档当时的快照，不应当作为当前数据范围的固定承诺。[AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)

### 2.3 AKShare 官方资料中的版本线索

AKShare 官方变更记录显示：该接口在 1.11.36 以 `stock_fear_greed_funddb` 名称新增，1.11.37 更名为 `index_fear_greed_funddb`，之后在 1.13.40、1.13.42、1.13.62 等版本记录过修复。[AKShare 官方 Changelog](https://akshare.akfamily.xyz/changelog.html)

截至本次研究，AKShare 官方 `main` 的当前指数源码目录列表中没有名为 `index_fear_greed_funddb` 的独立文件，当前在线数据字典也没有检索到该接口条目。[AKShare 官方 `akshare/index` 目录](https://github.com/akfamily/akshare/tree/main/akshare/index) · [AKShare 当前数据字典](https://akshare.akfamily.xyz/data/index.html)

这只能证明“当前 main 的公开目录/数据字典未列出该接口”，不能单凭目录缺失断言历史代码契约已经失效；因此本笔记把上面的输入/输出表标记为“历史公开契约”，而不是当前版本可用性的保证。

## 3. 相关六项情绪指标

韭圈儿公开科普明确说，50ETF 波动率之外还有五项情绪指标，并称六项综合加权得到恐惧贪婪指数。[韭圈儿公开科普](https://www.weibo.com/ttarticle/p/show?id=2309404636475210989882)

| 序号 | 公开名称 | 公开口径/含义 |
| --- | --- | --- |
| 1 | 50ETF 波动率 | 以衍生品价格隐含的预期波动率衡量市场对未来波动的预期；公开科普举例说明 20% 表示预期年化波动率约为 20%。 |
| 2 | 北上资金：陆股通累计买入净额 | 观察累计买入成交净额相对均线的偏离；正向偏离被解释为资金流入/偏多，反之偏空。 |
| 3 | 股价强度：创新高个股数量占比 | 观察创近一年新高的个股占比；占比越高表示市场广度/强势程度越高。 |
| 4 | 升贴水率：沪深300股指期货升贴水 | 期货升水（正）被解释为更乐观，贴水（负）被解释为更谨慎/偏空。 |
| 5 | 避险天堂：股债回报差 | 比较一段期间的股票与债券回报；公开示例使用沪深300回报率减国债净价指数回报率，并举例采用过去 20 个交易日。 |
| 6 | 杠杆水平：融资买入占比 | 融资买入额占两市总成交之比，用于描述场内借钱交易的热情和市场杠杆水平。 |

六项名称、方向性解释及部分示例窗口均来自韭圈儿公开科普；该材料没有给出每项数值权重，也没有说明各项是否始终使用上述示例窗口。[韭圈儿公开科普](https://www.weibo.com/ttarticle/p/show?id=2309404636475210989882)

## 4. 明确未公开的底层细节

以下内容在本次核验到的 FundDB 页面、韭圈儿公开科普和 AKShare 公开接口说明中没有看到可复核的数值定义：

- 六项指标的具体权重；
- 各项指标如何从原始值转换到共同尺度（例如百分位、标准化或截断）；
- 滚动窗口、样本起点和再平衡/更新时点的完整规则；
- 期权波动率的精确合约集合与期限选择；
- “陆股通累计买入净额”“创新高个股数量占比”“融资买入占比”等字段的缺失值、停牌股、退市股及市场范围处理；
- 两个 `symbol` 是否只改变返回的 `index` 对照列，还是同时改变 `fear` 的底层计算样本；
- 历史修订、回填和版本迁移规则。

因此，当前可证实的结论是“六项指标综合加权、输出 0–100 情绪读数”，而不是“六项等权平均”或任何可自行复算的具体公式。公开源码/接口契约只足以支持请求参数和三列响应字段；在没有 FundDB 公式或权重原文的情况下，不应从返回值反推权重。[韭圈儿公开科普](https://www.weibo.com/ttarticle/p/show?id=2309404636475210989882) · [AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)

## 5. 可复用的最小证据边界

如果后续任务需要接入该数据源，当前证据只支持以下最小假设：

1. 口径面：每次请求都必须显式传入 `symbol`，取 `上证指数` 或 `沪深300`；“默认上证指数”只能是界面的初始选择，不能省略请求标的。[AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)
2. 结果面：读取 `date`、`fear`、`index` 三列；不要把其他网页图表字段当成已承诺的 API 字段。[AKShare 接口公开说明](https://jishu.proginn.com/doc/674566248d0c0c4d3)
3. 计算面：把 `fear` 当作 FundDB 发布的综合情绪值；不要在本地复制或假设底层权重、窗口和公式。[FundDB 恐贪指数页面](https://www.funddb.cn/tool/fear) · [韭圈儿公开科普](https://www.weibo.com/ttarticle/p/show?id=2309404636475210989882)
4. 时效面：公开科普称该数据通常在收盘后更新完成，因此不应把它描述为盘中实时指标。[韭圈儿公开科普](https://www.weibo.com/ttarticle/p/show?id=2309404636475210989882)

## 6. 本次接入的边界

本次实现把 FundDB A 股口径作为独立数据源接入，不修改已有 CNN 美国/全球
Fear & Greed 模块，也不把两者合并为同一个字段或决策指标。

- 当前项目虚拟环境中的 AKShare 版本没有可调用的
  `index_fear_greed_funddb`，因此实现不伪装成仍然可用的 AKShare 调用。
- 接入适配器复用 FundDB 恐贪页面当前公开网页客户端所请求的图表数据，先校验
  `date/fear/index` 三列，再落成本地每日缓存；接口或加密响应变化时显式降级，
  不把未知响应静默解释成新数据。
- 两个口径分别以显式的 `symbol` 请求刷新；缺少标的的 API 请求直接返回参数错误，
  不隐式猜测或替换为 CNN 指数。
- 页面新增独立的 A 股面板和
  `/api/v1/market/ashare-fear-greed` 入口；CNN 原有
  `/api/v1/market/fear-greed`、决策面板和 RSI 机会逻辑保持原口径。
- 面板只展示当前 A 股恐贪分数、所选基准点位和有限历史；六项底层指标仍只作为
  页面研究背景，不在本地重复计算或推测权重。
