# 量化概念速览

这是面向计算机背景、金融/数学只有本科基础读者的简明速览。运行 `qm serve` 后点击
页头“帮助”，可阅读内置的系统手册、核对项目与真实市场的规则边界，并使用六个研究
计算工具；本页保留为适合快速查阅的命令行文档。每个概念给出直觉、公式与在本项目中的位置。

## 因子（Factor）

**直觉**：给每只股票每天打一个分，分高的（按约定）更值得买。
动量因子 = 「过去涨得多的分高」；反转因子 = 「最近跌得多的分高」。

**数据形态**：本项目中因子值是一张表（交易日 × 股票），代码里叫「面板」。

## IC / RankIC / ICIR

**IC（信息系数）**：某一天，全市场股票的「因子值」与「下期收益」的相关系数。
相关性越强，说明这个分数越能预测涨跌。

**RankIC**：先把两列都换成排名再算相关（Spearman 相关），不被极端值带偏，
是 A 股研究的默认口径。

**ICIR** = IC均值 / IC标准差：不仅要预测得准（均值高），还要天天稳定
（波动小）。类比信噪比。

**经验值**：|RankIC 均值| > 0.03 值得研究，> 0.05 是好因子；ICIR > 0.3 算稳定。
在 `qm factor-test` 输出与 Web 因子页可以看到。

## 分层回测（Quantile Backtest）

每天按因子值把股票分成 5 组（Q1 最低 … Q5 最高），各组等权持有算净值。
**好因子的特征是「单调」**：Q5 > Q4 > Q3 > Q2 > Q1。
如果只有 Q5 强、中间乱序，多半是几只极端股撑起来的假象。
`monotonicity` 指标就是分组收益与组号的相关系数，越接近 1 越单调。

## 多空组合与纯多头

「做多 Q5、做空 Q1」的收益剔除了大盘涨跌，是评价因子本身的干净口径。
但 A 股个股做空困难（融券贵且少），实盘通常只做纯多头（买 Q5），
所以还要看 Q5 相对基准（如沪深300）的超额收益。

## 未来函数（Look-ahead Bias）

用「当时不可能知道的信息」产生信号，回测无敌、实盘亏钱。最常见的形态：
用当日收盘价算信号又假设当日以收盘价买入。本项目全链路强制
「T 收盘出信号 → T+1 开盘成交」，表达式算子也只提供向后看的窗口。

## 常用绩效指标

| 指标 | 公式（直觉） | 经验参考 |
| --- | --- | --- |
| 年化收益 | 总收益折算为复利年率 | 与基准比较才有意义 |
| 最大回撤 | 净值从峰到谷最大跌幅 | 承受不了 30% 回撤就别选回撤 30% 的策略 |
| 夏普比率 | (年化收益−无风险利率)/年化波动 | > 1 不错，> 2 很好 |
| 卡玛比率 | 年化收益/最大回撤 | > 1 及格 |
| 信息比率 | 超额收益/跟踪误差 | 衡量「稳定跑赢基准」的程度 |
| 胜率 | 盈利天数占比 | 结合盈亏比看，单独无意义 |

## TWR 与 XIRR（实盘账本）

你年中加仓 10 万，年底账户涨了——到底是「策略赚的」还是「你转进来的」？

- **TWR（时间加权收益率）**：把出入金的影响剔除，衡量策略水平，
  可与指数直接比较。
- **XIRR（内部收益率）**：把每笔出入金当现金流解贴现率，衡量你的钱
  实际的年化增速，受出入金择时影响。

两者都在 `qm ledger report` 中输出。

## A 股交易规则速记（回测引擎已内置）

- **T+1**：今天买的股票最早明天卖。
- **涨跌停**：主板 ±10%、创业板/科创板 ±20%、北交所 ±30%；
  涨停买不进（排队买不到）、跌停卖不出。
- **成本**：佣金约万 2.5（最低 5 元，双边）+ 印花税 0.05%（仅卖出）
  + 过户费 0.001%。频繁交易时成本是收益的头号杀手。
- **整手**：买入必须是 100 股整数倍。

## 因子挖掘的过拟合警告

遗传规划/LLM 可以在任何数据里「挖出」高 IC 表达式——包括纯噪声。

共享多周期模型采用更严格的滚动协议。每个开发折只使用之前 756 个交易日训练，训练区与
验证区之间留出不短于最长 7 日标签的 purge；参数和模型族只看开发期 OOF。全部候选的
1 / 3 / 5 / 7 日检验属于同一个假设族，统一做 BH-FDR。推荐方案冻结后，末尾 252 个交易日
才按每 20 日重训的方式开启一次密封评估。概率的 isotonic / Platt 校准也只用开发期 OOF，
不能用密封标签“修正”概率。密封区失败代表本次没有候选，而不是继续调参直到通过。

回测再分成两种研究等级：`production` 必须有 PIT 历史成分、官方交易日历、实际公告日、
未复权开收盘、真实涨跌停/停牌和复权因子；缺一项就停止。`sandbox` 可以用缓存近似做探索，
但它产生的模型不能晋升 Champion，也不能伪装成生产回测证据。

Python AutoMiner 同样遵守这条纪律。它不是让模型直接接触数据或自由运行 Python：模型
只提出 `compute(features, params)`，本地静态策略和隔离子进程限制为 pandas/numpy
向量运算。数据按 TRAIN / VALID / TEST 三段切开，中间加入不短于最长预测周期的 purge；
参数必须落在邻域表现平滑的平台，候选通过 BH-FDR 和多目标 Pareto 排序后才冻结入围顺序，
最后一次性开启 TEST。TEST 指标不能用于继续提示模型、换参数或重排候选。

候选进入后续统一验证时还必须经过四类鲁棒性门禁：循环移动区块 Monte Carlo 保留收益与
IC 的时序依赖；参数敏感性检查窗口邻域是否为平台；WFA 检查逐折同号、训练到测试的衰减
和最差折；穿透性测试继续拆到年度、趋势/波动状态、高低流动性及个股贡献集中度。这里的
失败只会留下可审计的拒绝理由，不会触发“看完结果再调一次”的隐性数据窥探。

防过拟合的基本纪律：

1. **样本外验证**：用 2020-2022 挖，用 2023-2024 验，样本外 IC 掉一半是常态，
   归零说明是过拟合。
2. **逻辑先行**：解释不通的表达式（如 `ts_corr(low, volume, 3) ** 5`）
   再高的 IC 也别用。
3. **复杂度惩罚**：越长的表达式越可疑（挖掘器已内置 size 惩罚）。
4. **多周期稳健**：换 5/10/20 日持有期都有效才算数。
